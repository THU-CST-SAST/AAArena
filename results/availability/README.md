# Frozen player availability

The 12 game directories contain `runnable.json` availability records for the paper's archived player submissions. These records identify runnable entries and preserve diagnostic evidence. They are distinct from the complete source archives in `assets/`.

Formal evaluations use the fixed reference leaderboard selected by the resource builder. A player's presence in the archive alone does not make it an eligible evaluation opponent. Each run seals its exact opponent list in `controller/opponent-pool.json`.

See [package layout](../../docs/layout.md) and [runtime requirements](../../docs/runtime.md).
