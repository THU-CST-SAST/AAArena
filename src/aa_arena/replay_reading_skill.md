# AA-Arena replay-reading skill

Use this workflow for every small-match replay:

1. Read the adjacent `replay.json` first. It is the bounded, public per-round
   record: actions, state changes, and the official result. Never search for or
   open private Saiblo/controller files.
2. Read the adjacent `replay.md` next. It is the authoritative natural-language
   narration generated by the game evaluator. Treat `未识别动作` or a missing
   replay as an infra/correctness signal, not as a strategic fact.
3. Compare the candidate and opponent action/state sequence by phase: opening,
   first material advantage, decisive transition, and terminal state. Record one
   falsifiable hypothesis and the smallest strategy change that tests it.
4. Keep raw evidence in `artifacts/` only when it is needed to reproduce a
   conclusion. Put the short conclusion and next test in `notes/`.

The public replay is deliberately bounded. If it contains `replay_omitted`, the
private renderer dump was too large and must not be recovered; use the official
result and run a smaller, targeted match instead.

Game-specific fields and action names are defined by `replay/format.md` and
`replay/guide.md`. Do not infer semantics from undocumented numeric IDs.
